# 🏎️ F1 Overtake

F1 Overtake is a Formula 1 merchandise e-commerce website built using Laravel as a Web Programming course project.

This project provides a modern and responsive online shopping experience for Formula 1 fans to explore and purchase merchandise from various F1 teams and drivers.

---

## ✨ Features

* 🏁 Formula 1 merchandise catalog
* 👕 Product detail pages
* 🛒 Shopping cart system
* 🔍 Product search feature
* 👤 User authentication (Login & Register)
* 📱 Responsive user interface
* 🎨 Modern Formula 1 themed design

## ⚙️ Installation

### 1. Clone Repository

```bash
git clone https://github.com/rezakzz/F1-Overtake.git
```

### 2. Navigate to Project Folder

```bash
cd F1-Overtake
```

### 3. Install Dependencies

```bash
composer install
npm install
```

### 4. Copy Environment File

```bash
cp .env.example .env
```

### 5. Generate Laravel Application Key

```bash
php artisan key:generate
```

### 6. Configure Database

Create a new MySQL database and update the database configuration inside the `.env` file.

Example:

```env
DB_DATABASE=f1_overtake
DB_USERNAME=root
DB_PASSWORD=
```

### 7. Run Database Migration

```bash
php artisan migrate
```

### 8. Run the Application

```bash
php artisan serve
```

Access the application via:

```text
http://127.0.0.1:8000
```
